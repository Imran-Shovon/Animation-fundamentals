# Animation fundamentals

A dependency-free HTML, CSS and JavaScript animation reference. Open `index.html` directly in a browser; no build or installation is required.

| Page | Demos | Contents |
| --- | --- | --- |
| `index.html` | 1–226 | Animation principles and core web motion |
| `more.html` | 227–364 | Additional UI, navigation and decorative patterns |
| `part4.html` | 365–408 | Modern CSS, forms, gestures, data and games |
| `part5.html` | 409–413 | Walking gait, moiré, standing wave, cycloid and Lissajous studies |
| `part6.html` | 414–420 | Double pendulum, inverse kinematics, flocking, cloth, fluid ink, reaction–diffusion and spring damping |
| `part7.html` | 421–426 | Sorting, pathfinding, maze generation, rigid bodies, skeletal skinning and WebGL vertex displacement |

Each page has Show code, Copy, Replay and Pause all motion controls. Reduced-motion preferences start playback paused; off-screen demos pause automatically. Styles and scripts for each additional part use the matching filename alongside shared `styles.css`.

Part 7 includes three sorting algorithms, A* and Dijkstra search, seeded maze generation, rotating box collisions, weighted mesh skinning and a WebGL wave with a canvas fallback. Finite algorithms stop on completion and can be replayed.

Project conventions are in `.claude/skills/animation-playground/SKILL.md`. The catalog contains 426 demos, not an exhaustive list of every possible animation.
