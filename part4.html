Newer CSS features for motion

Recent CSS removes most of the JavaScript that motion used to need: animating elements in and out of display: none, native dialogs and popovers that animate, transitions to height: auto, tooltips that position themselves, shared-element transitions and real spring curves. Each demo says which browsers support it; where a feature is missing, the element still works, just without the motion.

Animate from display: none with @starting-style

Toggling display used to kill transitions. @starting-style gives the browser a "before" state for the first frame, and transition-behavior: allow-discrete keeps the element displayed until its exit transition ends. Chrome/Edge 117+, Safari 17.5+, Firefox 129+.

Transition to height: auto

interpolate-size: allow-keywords lets height animate between 0 and auto, and ::details-content lets you style the hidden part of a <details>. Result: a smooth native accordion in CSS only. Chrome/Edge 131+; elsewhere it opens instantly.

On the web: FAQs, settings groups, "show more" sections.

Is it really CSS only?

Yes. The browser measures the auto height for you and animates to it.

What about older browsers?

They ignore the new properties, so the panel simply opens without animation.

Does it work for width too?

It works for any size keyword: auto, min-content, max-content, fit-content.
